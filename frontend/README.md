# Shuaq · Frontend, стиль и дизайн

Лендинг IT-студии Shuaq: сайты, серверы, Telegram- и WhatsApp-боты и автоматизация для кафе, ресторанов и любого бизнеса.
Статичная страница без сборки: HTML + CSS + ES-модули, 3D на Three.js из CDN.

---

## 1. Идея

**Шуақ** по-казахски значит «тёплый солнечный свет». Отсюда весь визуальный язык: **светлое небо, пухлые облака и солнце**.

Сайт должен ощущаться как ясное утро: воздушно, мягко и спокойно. При этом он должен выглядеть дорого и инженерно точно. Мягкость задают форма и цвет, профессионализм — сетка, отступы и честный текст.

Три слова стиля: **облачный · тёплый · аккуратный**.

## 2. Структура

```
frontend/
├── index.html     — разметка всех секций + встроенный спрайт иконок
├── styles.css     — токены, компоненты, секции, адаптив
├── script.js      — навигация, появление при скролле, портфолио, демо-чат, форма
├── scene.js       — 3D-сцена первого экрана (Three.js 0.160)
├── projects.js    — данные портфолио (единственное место, где правятся кейсы)
└── assets/
    ├── favicon.svg
    └── logo.svg
```

**Запуск локально** (сайт + API заявок):

```bash
node backend/server.js
```

Сайт откроется на http://localhost:3000. Без бэкенда страница тоже работает: если `/api/orders` недоступен, форма предлагает отправить заявку прямо в Telegram.

**Деплой:** `vercel.json` раздаёт папку `frontend/` как статику. Бэкенд деплоится на Render (`render.yaml`). Если фронт и API живут на разных доменах, задайте `window.SHUAQ_API_URL` до подключения `script.js`.

## 3. Цвет

Все цвета заданы токенами в `:root` в начале `styles.css`. Ничего не красим «голым» hex-кодом в компонентах.

| Тон   | Пастель (`--x`) | Глубокий (`--x-d`) | Где используется |
|-------|-----------------|--------------------|------------------|
| sky   | `#D6E7FF` | `#5B8DFF` | сайты, Telegram, фокус |
| lav   | `#E3DDFF` | `#8673FF` | серверы, прототипы |
| mint  | `#D3F5E6` | `#2DBE8C` | WhatsApp, успех, «онлайн» |
| peach | `#FFE0D1` | `#FF8C66` | кафе и рестораны |
| sun   | `#FFEDB0` | `#F5A623` | AI, блики, маркер в заголовке |
| rose  | `#FFDDEA` | `#F0699B` | дизайн, ошибки формы |

**Нейтральные цвета:** фон `--bg #F5F7FF`, текст `--ink #1D2346` (глубокий сине-фиолетовый, не чёрный), вторичный `--ink-2`, подписи `--ink-3`.

Правила:
- Пастель — для фона, глубокий тон — для линий и акцентов. Глубокий тон не заливает большие площади.
- Главная кнопка всегда тёмная (`--ink`). Цветных кнопок нет: так CTA читается сразу.
- Тон задаётся атрибутом `data-tone="sky|lav|mint|peach|sun|rose"`. Он выставляет `--tone` и `--tone-d`, а их уже используют карточки, иконки и обложки.
- Никакого градиентного текста, неона и кислотных цветов.

## 4. Типографика

| Роль | Шрифт | Насыщенность |
|------|-------|--------------|
| Заголовки, кнопки, цифры | **Nunito** — скруглённые окончания, «мягкий» гротеск | 800–900 |
| Текст | **Manrope** — спокойный и хорошо читаемый | 400–700 |

Оба шрифта поддерживают кириллицу и подключаются из Google Fonts.

- Заголовки плотные: `letter-spacing: -.035em`, `line-height: 1–1.05`, `text-wrap: balance`. Принудительные `<br>` в заголовках не ставим: перенос подбирает браузер.
- H1 — `clamp(2.5rem, 5.3vw, 4.9rem)`, H2 — `clamp(2.1rem, 4.6vw, 3.7rem)`.
- Ключевое слово в H1 выделяется маркером `.marker`: мягкая жёлто-персиковая подложка, которая «прорисовывается» слева направо.

## 5. Форма и глубина

- **Скругления:** `--r-sm 14px`, `--r 24px`, `--r-lg 36px`. Большие блоки (HoReCa, контакты) — 48px. Кнопки и чипы — пилюли (`999px`).
- **Тени** только мягкие и цветные (сине-лавандовые), без чёрного: `--shadow-sm`, `--shadow`, `--shadow-lg`.
- **Стекло** (`.glass`) — белый на 62% + `backdrop-filter: blur(18px)` + белая 1px-рамка. Используется для плашек поверх неба.
- **Фон-небо** (`.sky`) — фиксированный слой из радиальных градиентов, облака медленно дрейфуют и слегка уходят в параллакс при скролле, сверху едва заметное зерно.

## 6. Фирменная особенность: «облако и луч»

Главный приём, который отличает Shuaq от шаблонных сайтов. Он повторяет 3D-сцену первого экрана в плоском виде.

```
 ╭──────────╮ ●  ← солнечный блик (шуақ): тёплая точка с белым ободком
 │  ╭────╮  │
 │  │ ☁  │  │   ← иконка: контур глубоким тоном, внутри белое «облачко»
 │  ╰────╯  │
 ╰──────────╯   ← «подушка»: пастельный squircle, свет сверху-слева
```

1. **Иконки — Phosphor Icons, стиль duotone** (MIT, v2.1.1). У duotone два слоя: контур и полупрозрачная заливка. Мы перекрашиваем заливку в **белый**, и внутри каждой иконки появляется маленькое облако.
2. **Подушка** `.puff` — скруглённый квадрат (`border-radius: 36%`) с радиальным градиентом от белого к пастели тона и внутренним светом. На вид как пластилиновые объекты в 3D-сцене.
3. **Блик** — тёплая солнечная точка в правом верхнем углу подушки. Это подпись бренда, она есть у каждой иконки на подушке.
4. **Движение:** при наведении на карточку блик разгорается (увеличивается и светится), а иконка слегка подпрыгивает и наклоняется.

### Как использовать

```html
<!-- иконка на подушке -->
<span class="puff puff--md" data-tone="mint" aria-hidden="true">
  <svg class="i"><use href="#i-whatsapp-logo"/></svg>
</span>

<!-- просто иконка в тексте или кнопке -->
<svg class="i" aria-hidden="true"><use href="#b-arrow-right"/></svg>
```

Размеры подушки: `puff--xs` 26px (без блика, для списков), `--sm` 38px, `--md` 50px, `--lg` 68px, `--xl` 84px.

Префиксы в спрайте:
- `#i-*` — duotone, для смысловых иконок (услуги, этапы, контакты);
- `#b-*` — bold, для служебных значков (галочка, стрелки, закрыть).

### Как добавить иконку

Спрайт встроен в начало `<body>` в `index.html` (так он работает везде, включая браузеры, которые блокируют внешний `<use>`).

1. Найдите иконку на [phosphoricons.com](https://phosphoricons.com) и возьмите SVG в весе **Duotone** (или **Bold** для служебных).
2. Добавьте в спрайт `<symbol id="i-имя" viewBox="0 0 256 256">…</symbol>`.
3. В duotone-иконке замените у слоя заливки `opacity="0.2"` на
   `style="fill:var(--i-fill,currentColor);opacity:var(--i-o,.2)"`. Тогда внутри `.puff` он станет белым облачком, а вне подушки останется обычным duotone.

Чего не делать: эмодзи и символы (✓ ✈ ☕ ↗) вместо иконок, иконки из разных наборов, иконка на подушке без блика.

## 8. 3D-сцена (`scene.js`)

Пастельные «пластилиновые» объекты на `MeshPhysicalMaterial`: clearcoat + sheen + окружение `RoomEnvironment`, тоновая компрессия ACES.

| Объект | Смысл | Клик ведёт в |
|--------|-------|--------------|
| Облако | бренд, облачные решения | `#contact` |
| Солнце с кольцами | «шуақ» | `#top` |
| Телефон с пузырями | Telegram-боты | `#services` |
| Мятный пузырь с точками | WhatsApp-боты | `#services` |
| Сервер с огоньками | backend | `#services` |
| Окно браузера | сайты | `#work` |
| Чашка кофе с паром | автоматизация HoReCa | `#horeca` |

**Поведение:**
- объекты появляются по очереди с пружинкой и покачиваются;
- сцена следует за мышью, её можно вращать перетаскиванием;
- при наведении объект подрастает и показывает подпись, по клику — плавный переход в раздел;
- когда hero уходит за экран, рендер на паузе.

**Как менять:** каждый объект добавляется через `addItem(group, { label, target, pos, rot, amp, speed, delay, scale })`. Цвета — в объекте `M` вверху файла, они совпадают с CSS-токенами. Если WebGL недоступен, у `.hero__visual` появляется класс `.no-webgl` с плоской заглушкой.

## 9. Движение

- Кривые: `--ease` (плавное замедление) для появления, `--spring` (лёгкий перелёт) для наведения и нажатия.
- Блоки появляются снизу вверх при скролле (`.reveal`), соседние — «лесенкой» с шагом 70 мс.
- Медленное, «облачное»: дрейф облаков 60–90 с, покачивание плашек 6 с. Ничего не мигает резко.
- При `prefers-reduced-motion: reduce` все анимации отключаются, а 3D-сцена показывается статично.

## 10. Портфолио

Все кейсы лежат в `projects.js`. Карточки, фильтр, счётчик в hero и модальное окно собираются из этого массива автоматически.

```js
{
  id: "qunar",
  title: "Qunar",
  category: "web",            // или массив: ["bots", "ai"]
  cover: "dashboard",         // тип нарисованной обложки
  tone: "mint",               // цвет обложки
  kicker: "SaaS-платформа · Агро",
  summary: "Коротко — для карточки",
  details: "Подробно — для модального окна",
  result: "Что получил клиент",
  tags: ["React", "FastAPI"],
  links: { live: "https://…", github: "https://…" }
}
```

На главной сразу видны первые 6 проектов, остальные открываются кнопкой «Показать все проекты».

## 11. Форма заявки

- Отправляет JSON на `POST /api/orders` (`backend/server.js`). Бэкенд сохраняет заявку и шлёт уведомление в Telegram.
- Если API недоступен, клиент всё равно видит экран успеха и кнопку «Продолжить в Telegram» с готовым текстом заявки.
- **WhatsApp:** впишите номер в `CONFIG.whatsapp` в начале `script.js` (формат `77001234567`), и в контактах появится кнопка.
- Кнопки «Выбрать» в тарифах и «Автоматизировать заведение» сами отмечают нужную услугу в форме (атрибут `data-service`).

## 12. Адаптив и доступность

- Брейкпоинты: 1080px (2 колонки), 920px (мобильное меню, 3D над текстом), 640px (1 колонка).
- На телефоне 3D-сцена стоит над заголовком, лишняя плашка скрыта, фильтр проектов прокручивается по горизонтали.
- Контраст текста `--ink` / `--ink-2` на светлом фоне — уровень AA.
- Видимый фокус (`:focus-visible`): синяя обводка 3px.
- Декоративные иконки помечены `aria-hidden`, у canvas есть описание, демо-чат объявляется через `aria-live`.
