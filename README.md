# Shuaq — Digital Agency & Technology Studio

> **Shuaq (Шуақ)** — цифровое агентство нового поколения. Разработка технологичных web-сервисов, AI-автоматизации, IoT-интеграций и browser extensions под ключ.
>
> 💎 **Дизайн-стиль:** **Apple & Arc Browser Aesthetic · Cloud Horizon & Stratosphere**.

---

## 🧭 Концепция и позиционирование

* **Имя бренда:** **Shuaq** (казах. *Шуақ* — солнечный луч, тепло, созидательный свет, озарение).
* **Смысл:** Мы вносим ясность, скорость и технологический свет в сложные бизнес-задачи. Превращаем сырые идеи в работающие цифровые продукты.
* **Тональность:** Технологично, молодо, уверенно, дорого. Атмосфера полета на высоте 10 000 метров над облаками (High Altitude Tech).

## 🎨 Дизайн-система (Закреплена)

### 1. Архитектура атмосферы: «Над облаками» (Cloud Horizon)
* **Концепция:** Сайт уходит от мрачных заезженных темных шаблонов к сияющей эстетике высоты, чистого неба и рассвета.
* **Фоновый слой (`sky-container`):**
  * Глубокий градиент стратосферы: от ультрамарина к мягкому утреннему лазурному и персиковому горизонту.
  * **Volumetric Animated Clouds:** 3 слоя многослойных парящих облачных туманностей (`cloud-layer-back`, `cloud-layer-mid`, `cloud-layer-front`) с мягким размытием (45–60px) и медленным встречным дрейфом.
  * **Sun Glow:** Рассветный световой шар (Shuaq warmth) с пульсацией ореола вокруг центра композиции.

### 4. Анатомия ключевых компонентов

#### А. Плавающий Dock-хедер (`floating-header`)
* Форма капсулы (Pill Island), закрепленная сверху экрана.
* Векторный 3D-знак Shuaq с градиентом.
* Индикатор высоты: `10,000m · Cloud Horizon` с пульсирующим циановым маяком.
* Быстрые кнопки: GitHub (`@Dyman17`) и кнопка связи Telegram с фирменным градиентом.

#### Б. Контроллер категорий (Arc Segmented Control)
* Парящий стеклянный сегментированный контроллер:
  * `Все проекты (9)`
  * `Web & SaaS (4)`
  * `AI & Vision (4)`
  * `IoT & Hardware (3)`
  * `Extensions (1)`
* Мягкое переключение без перезагрузки страницы.

#### В. Карточки проектов (macOS Window Style)
* Окно в стиле macOS с цветными точками управления (traffic lights: red, yellow, green).
* Интерактивный темный экран с превью интерфейса (телеметрия, графики данных, статус-пилюли: `LIVE SAAS`, `ESP32 STREAM`, `YOLOv8 ACTIVE`, `MANIFEST V3`).
* Бейджи стека технологий (`React`, `FastAPI`, `PostgreSQL`, `ESP32`, `YOLOv8`).
* Кнопка `Скриншот 🔍` для открытия в полноэкранном режиме и прямая ссылка на репозиторий GitHub.

#### Г. Полноэкранный Lightbox (Apple VisionOS / macOS Modal)
* Открывается плавно с размытием фона `backdrop-filter: blur(28px)`.
* Детальный разбор архитектуры проекта, каналы передачи данных, метрики эффективности и кнопка перехода в репозиторий.
* Закрытие по кнопке Esc, клику вне окна или красной точке macOS.

#### Д. Стеклянный конфигуратор заказа (Shuaq Order Studio)
* Вызов по кнопкам «Заказать проект» в Dock-хедере, в Hero и прямо из карточек/Lightbox.
* Выбор направления (`Web & SaaS`, `AI & Automation`, `IoT & Hardware`, `Chrome Extension`, `Другое`).
* Поля задачи, ориентировочного бюджета, желаемых сроков и контактов.
* **Двойной канал согласования:**
  1. **Прямая отправка на сайт:** заказ сохраняется на сервере в базе `orders.json` со статусом `new` и автоматически шлет уведомление в Telegram бот.
  2. **Мгновенный переход клиентом в Telegram:** кнопка «Сформировать бриф в Telegram» открывает мессенджер с предзаполненным структурированным текстом задачи.

## 🚀 Запуск проекта

### 1. Запуск Backend (с раздачей Frontend)
```bash
cd backend
npm install
node server.js
```
Сервер запустится на `http://localhost:3000` и будет одновременно обслуживать REST API и отдавать красивый клиентский сайт из папки `frontend/`.

### 2. Настройка Telegram уведомлений
В файле `backend/.env` укажите:
```ini
PORT=3000
TELEGRAM_BOT_TOKEN=123456:ABC-DEF...   # Токен от @BotFather
TELEGRAM_CHAT_ID=-100123456789         # Ваш Chat ID или ID группы
TELEGRAM_MANAGER_USERNAME=dyman_kz     # Юзернейм менеджера для диалогов
```

## 🛠 REST API эндпоинты

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| `POST` | `/api/orders` | Создание новой заявки с сайта и отправка в Telegram |
| `GET` | `/api/orders` | Просмотр всех заказов (фильтр: `?status=new\|approved`) |
| `GET` | `/api/orders/:id` | Просмотр одного заказа по ID (`SHQ-1001`) |
| `PATCH` | `/api/orders/:id` | Согласование заказа (обновление статуса и заметок) |
| `GET` | `/api/health` | Проверка работоспособности сервера |
